# 4. Administrative divisions

Help users understand how a country organizes territory, public authority, representation and statistics. These arrangements may overlap without forming one universal hierarchy.

## Categories to learn

- **Territorial administration:** the country's regions, states, provinces or equivalent units.
- **Local government:** municipalities, councils, towns, villages and their documented responsibilities.
- **Electoral geography:** constituencies, wards, polling districts and representation.
- **Statistical geography:** census districts, enumeration areas and reporting regions.
- **Traditional or special governance:** recognized traditional authorities, autonomous areas and special arrangements.
- **Boundary change:** reorganizations, mergers, code changes and different published editions.

Administrative, electoral, statistical and traditional schemes should be separately identified. A matching name does not prove a matching boundary or legal function.

## Interactive learning

| User activity                     | App accommodation                                                                        |
| --------------------------------- | ---------------------------------------------------------------------------------------- |
| Ask how the country is divided    | A scheme selector with local terms, purpose, source and edition                          |
| Click an available area           | Highlight its actual polygon and show its identity and scheme                            |
| Drill into a supported local area | Load reviewed child geometry and update breadcrumbs                                      |
| Ask who is responsible there      | Show documented institutions and responsibilities separately from the boundary directory |
| Compare schemes or editions       | Distinguishable overlays or a split view, with overlap/change explanations               |

Allow separate schemes to remain visible as separate structures. Preserve official numbering gaps and retired identifiers rather than manufacturing a tidy hierarchy.

## AI-orchestrated example

**Question:** "Show the local authorities and explain how they differ from electoral areas."

AI identifies which schemes and geometry editions are actually available. It displays reviewed polygons using the country's terms, explains each scheme's purpose and retrieves any documented institutional relationships.

If the country only has historical reference districts, AI labels that coverage and explains that it cannot show current local authorities from those polygons. In Botswana, historical reference districts must remain distinct from local-authority and electoral schemes. In Namibia, regional constituencies, local authorities and traditional arrangements require separate treatment.

The user can select an area and ask "What institution serves this area?" only where that relationship is sourced.

## Evidence and integration

Use official demarcation agencies, local-government legislation and directories, electoral authorities and statistical agencies. Retain source codes, local type names, scheme IDs, effective dates, parent/overlap relationships, geometry vintage and licensing.

A future country adapter should describe its supported schemes and area types rather than map every country onto province → district → municipality → ward. Support parallel schemes and documented overlaps. Statistics need explicit geographic joins or reviewed crosswalks.

Reference polygons may be useful for navigation without proving current legal boundaries or administrative powers. Preserve the existing Namibia publisher-date conflict wherever the affected geometry is used.

**Current foundation:** 237 country/area profiles, dated reference geometry across 214 countries/areas, South African municipal/ward support and initial Botswana/Namibia scheme descriptions. Comprehensive local/electoral geometry and country-specific adapters remain expansion work.

## Learning outcome and completion check

The user can identify an area's scheme, source edition and purpose, and distinguish its boundary from an institution's powers. Verify country-specific labels, correct selection/parent joins, date caveats and restoration of the chosen edition in saved investigations.
